## Traceable Audit Ledger

| Finding ID | Component & File Path | Severity | Root Cause | User & System Impact | Remediation & Tests | Verification Status |
|---|---|---|---|---|---|---|
| **AUDIT-001** | `src/likby/config.py`, `src/likby/api/chat_sessions.py:41`, `src/likby/api/play.py:70` | **Critical** | `Settings` defines `bot_token`, but endpoints accessed `settings.telegram_bot_token.get_secret_value()`. | When client sends `X-Telegram-Init-Data` header, FastAPI raised unhandled `AttributeError: 'Settings' object has no attribute 'telegram_bot_token'`, crashing with 500 error and breaking Telegram Mini App authentication. | Added `@property def telegram_bot_token` to `Settings`, normalized callers to `bot_token`. Verified with `test_endpoint_authentication_via_init_data_header`. | **Verified** |
| **AUDIT-002** | `src/likby/telegram/security.py:14-60` | **Critical** | `validate_telegram_init_data` verified HMAC signature but did not validate `auth_date` timestamp freshness against current server clock. | Vulnerable to replay attacks: a captured or leaked initData query string could be replayed indefinitely to impersonate a Telegram user. | Enforced `max_age_seconds: int = 86400` (24h) with 300s clock-skew allowance. Stale data rejected with `None`. Verified with `test_telegram_init_data_replay_attack_rejected`. | **Verified** |
| **AUDIT-003** | `src/likby/api/play.py:644-694` | **High** | WebSocket endpoint `/api/v1/play/ws/{session_id}` accepted connections without validating caller authentication or checking session membership. | Any malicious user guessing or obtaining a `session_id` could eavesdrop on live game states or broadcast spoofed game actions. | Added token/initData authentication check and authorized participant verification against session participants. Non-participants rejected with WS 1008 Policy Violation. Verified with `test_websocket_unauthorized_intruder_rejected`. | **Verified** |
| **AUDIT-004** | `src/likby/main.py:488-510` | **High** | Missing request correlation ID (`X-Request-Id`), security response headers, and structured global exception handlers in FastAPI app. | Difficult log correlation during incidents; missing defense-in-depth security headers (`nosniff`, `SAMEORIGIN`, `strict-origin-when-cross-origin`); unexpected errors revealed raw unformatted responses. | Implemented `request_correlation_and_security_middleware` and `custom_http_exception_handler`. Verified with `test_security_headers_and_correlation_id` and `test_http_exception_custom_handler`. | **Verified** |
| **AUDIT-005** | `src/likby/main.py:823-835` | **High** | Untracked background task creation in `telegram_webhook` via `asyncio.create_task` without task set retention or shutdown draining. | Tasks could be garbage-collected mid-execution by Python runtime; updates dropped during graceful container termination or redeployments on Render. | Added `app.state.active_update_tasks` set tracking with discard callbacks and 5-second graceful drain timeout in `lifespan` teardown. | **Verified** |
| **AUDIT-006** | `src/likby/static/play/styles.css` & `index.html` | **Medium** | Missing WCAG 2.2 AA accessibility features: no `:focus-visible` styling, no `@media (prefers-reduced-motion: reduce)`, missing ARIA attributes on modals and icon buttons. | Screen-reader and keyboard users had no visible focus rings; vestibular sensitivity sufferers had no reduced-motion override for 60fps canvas particles. | Added high-contrast `:focus-visible` rings, reduced-motion media query disabling canvas particles, and ARIA roles/labels across all interactive dialogs. | **Verified** |
| **AUDIT-007** | `src/likby/static/play/app.js:252-273` | **Medium** | Blanket `catch (e) { return null; }` in `apiCall` swallowed HTTP 4xx/5xx network failures silently. | Quota exhaustions and backend outages resulted in silent degradation to local offline engine without notifying users or logging diagnostics. | Added structured console warning telemetry, specific quota exhaustion toast warnings, and fallback diagnostics. | **Verified** |
