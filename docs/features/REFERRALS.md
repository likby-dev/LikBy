# LikBy Referral Engine & Fraud Prevention

---

## 1. Referral Mechanism

- Every user receives a unique referral link: `https://t.me/LikByBot?start=ref_<likby_id>`.
- When an eligible new user starts the bot and completes onboarding:
  1. The referrer is awarded **1 Spark Pass** (24 hours of temporary premium access).
  2. The newly referred user receives a welcome onboarding bonus.

---

## 2. Anti-Abuse & Fraud Controls

- **Self-Referral Prohibition:** A user cannot refer their own account or existing Telegram user ID.
- **Rolling Cap:** Maximum of **3 Spark passes per rolling 30-day window** to prevent referral spam and automated farming.
- **Account Maturity:** Referred users must complete profile setup and pass age verification before rewards are credited.
