# LikBy Privacy & User Controls

---

## 1. User Controls & Self-Service Commands

- `/profile` — View and edit profile details, bio, and languages.
- `/settings` — Manage notification preferences and discoverability toggle.
- `/privacy` — Review privacy commitments, export data, or initiate account deletion.
- `/block` — Block a user immediately, severing all messaging and discovery connections.
- `/report` — Submit an actionable report against abusive content.

---

## 2. Account Deletion Workflow (GDPR Compliance)

Upon invoking account deletion:
1. Profile visibility is revoked instantly.
2. Active friendship records and discovery tickets are terminated.
3. Media metadata is marked for purging; object storage assets are deleted via background cleanup.
4. A 30-day cryptographically pseudonymized tombstone is retained solely for abuse-prevention and legal compliance.
