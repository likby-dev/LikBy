# LikBy Subscription Entitlements & Tier Matrix

LikBy defines four canonical, server-enforced tiers: **`base`**, **`spark`**, **`premium`**, and **`diamond`**.

## 2. Downgrade & Expiration Rules

- **Friend Retention:** When a paid subscription or Spark pass expires and the user returns to `base` tier, existing friends are **never deleted**. The user simply cannot add new friends until their active friend count falls below 3.
- **Data Persistence:** Account settings, chat history, and shared media are permanently retained regardless of tier changes.
