# 03 — Research & Assumptions

| Webhook IP ranges: `149.154.160.0/20`, `91.108.4.0/22` | Telegram Bot API docs | 2026-10-15 |

### Assumptions

| Assumption | Risk if Wrong | Mitigation |
|---|---|---|
| Telegram does not inspect or filter bot message content beyond ToS enforcement | Medium — could block messages | Use Telegram-safe formatting; avoid content that violates Telegram ToS |
| Bot tokens remain stable unless regenerated by owner | Low | Store token in environment variable; document rotation procedure |
| Private chat messages are reliably delivered within seconds | Low | Add timeout handling for message relay |

### Open Questions

| Question | Impact | Status |
|---|---|---|
| Does Telegram enforce per-bot webhook response time limits? | Could cause missed updates on slow responses | REQUIRES RESEARCH — likely 60s timeout based on community reports |
| What happens when a user blocks the bot? | Bot cannot send messages; need graceful handling | REQUIRES RESEARCH — `sendMessage` returns error 403 |

## 4. SQLite

### Verified Facts

| Claim | Source | Verified |
|---|---|---|
| WAL mode allows concurrent reads with single writer | [SQLite WAL docs](https://www.sqlite.org/wal.html) | 2026-10-15 |
| Only one writer at a time, even in WAL mode | SQLite docs | 2026-10-15 |
| `busy_timeout` pragma retries on lock contention | SQLite docs | 2026-10-15 |
| `BEGIN IMMEDIATE` acquires write lock immediately, avoiding deadlocks | SQLite docs | 2026-10-15 |
| WAL mode does not work on network filesystems | SQLite docs | 2026-10-15 |
| `aiosqlite` wraps blocking calls in background thread | aiosqlite source | 2026-10-15 |
| Foreign key enforcement requires `PRAGMA foreign_keys = ON` per connection | SQLite docs | 2026-10-15 |

### Assumptions

| Assumption | Risk if Wrong | Mitigation |
|---|---|---|
| Single-instance deployment makes single-writer acceptable for MVP | High if scaled to multiple instances | Repository interface enables migration to PostgreSQL |
| `busy_timeout = 5000` is sufficient for MVP write contention | Medium | Monitor for `database is locked` errors; tune or add write queue |

### Architecture Decision Affected

- **ADR-003**: SQLite chosen for zero-cost local development; single-writer limitation accepted.
- **ADR-004**: Repository interfaces designed to swap to PostgreSQL.

## 5. Render Platform

### Verified Facts

| Claim | Source | Verified |
|---|---|---|
| Free web services sleep after 15 minutes of inactivity | [Render docs](https://docs.render.com/free) | 2026-10-15 |
| Cold start takes approximately 1 minute | Render docs | 2026-10-15 |
| 750 free instance hours per month per workspace | Render docs | 2026-10-15 |
| **Ephemeral filesystem** — all local data lost on restart/redeploy/sleep | Render docs | 2026-10-15 |
| Persistent disks NOT available on free tier | Render docs | 2026-10-15 |
| Free tier: 512 MB RAM, 0.1 CPU | Render docs | 2026-10-15 |
| Free PostgreSQL: 1 GB storage, expires after 30 days | Render docs | 2026-10-15 |
| Outbound SMTP blocked on free tier | Render docs | 2026-10-15 |

### Critical Implications

| Implication | Impact | Mitigation |
|---|---|---|
| SQLite database destroyed on every restart | **All user data lost** | Document clearly; use only for demo; production requires external DB |
| 15-minute sleep means webhook delivery may fail | Telegram retries, but delayed responses | Accept for demo; production needs paid tier or alternative |
| Cold start ~60s may timeout Telegram webhook | Missed updates during cold start | Telegram retries; first request after sleep may fail |
| 0.1 CPU limits concurrent operations | Slow matching under load | Acceptable for demo; production needs more resources |

### Architecture Decision Affected

- **ADR-009**: Render free tier accepted for demo only; production deployment requires either paid Render tier or Supabase external database.

### Open Questions

| Question | Impact | Status |
|---|---|---|
| Does Render free tier support custom health check paths? | Health monitoring | REQUIRES RESEARCH — likely yes |
| Can `render.yaml` configure webhook URL as environment variable? | Deployment automation | REQUIRES RESEARCH |
